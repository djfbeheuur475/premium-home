# Premium Home

A custom Home Assistant Lovelace card — a self-contained smart-home app
UI (Home / Climate / Lights / Humidity) with its own internal bottom
navigation. Personal/private component, not intended for the public
HACS store; added as a HACS custom repository.

## Install

HACS → Frontend → menu (top right) → Custom repositories → add this
repo's URL, category "Dashboard" → find "Premium Home" in the list ->
Download.

## Use

Add a card of type `custom:premium-home` to any dashboard.
